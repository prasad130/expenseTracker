# Expense Tracker Application

## 1. Project Overview

Expense Tracker is a full-stack web application developed to manage and monitor daily expenses. It allows users to record expenses, view expense details, and analyse spending through graphical representations.

## 2. Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* HTML
* CSS
* JavaScript
* Chart.js

## 3. Features

* Add new expenses.
* View all recorded expenses.
* Update existing expenses.
* Delete expense records.
* Calculate total expenses.
* Visualize expenses using charts.
* Store expense information in MySQL.

## 4. Project Architecture

Frontend:
HTML, CSS, JavaScript

Backend:
Spring Boot, REST APIs

Database:
MySQL

## 5. Database Configuration

1. Install MySQL.
2. Create the required database.
3. Configure database credentials using environment variables or local configuration.
4. Run the Spring Boot application.

## 6. How to Run the Project

1. Clone the repository.
2. Import the project into Spring Tool Suite.
3. Configure the MySQL database.
4. Run the main Spring Boot application.
5. Open your browser.

Application URL:
http://localhost:8080
